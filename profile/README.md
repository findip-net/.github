# FindIP

FindIP builds developer-friendly IP intelligence tools for geolocation, VPN and proxy detection, Tor detection, IP reputation, and website visitor risk analysis.

## FindIP Shield

FindIP Shield adds visitor risk intelligence to a website with one JavaScript SDK. It reports network signals such as VPN, proxy, Tor, relay, hosting, datacenter, and malicious-IP activity without collecting form values.
