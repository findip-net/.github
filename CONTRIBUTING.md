# Contributing

Thank you for helping improve FindIP's public projects.

Before opening a pull request:

1. Search existing issues and pull requests for related work.
2. Open an issue before making a large behavioral or API change.
3. Keep the change focused and include tests when behavior changes.
4. Run the repository's documented checks locally.
5. Explain what changed, why it changed, and any compatibility or privacy impact.

By contributing, you agree that your contribution may be distributed under the license of the repository.
